# Clínica Cuidar+

Aplicação responsiva de agendamento para clínicas, criada como projeto autoral de portfólio.

## Funcionalidades

- Escolha de especialidade, profissional, data, horário e modalidade.
- Validação de formulário e retorno acessível.
- Histórico pesquisável, filtros, cancelamento e exclusão.
- Indicadores de solicitações e atendimentos online.
- Dados salvos localmente no navegador.
- Layout responsivo e navegação por teclado.

## Como executar

Abra `index.html` no navegador. Não há dependências ou servidor obrigatório.

> Projeto demonstrativo. Nenhum agendamento é enviado a uma clínica real.
